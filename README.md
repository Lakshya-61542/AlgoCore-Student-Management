# AlgoCore — Student Record Management System

A menu-driven Student Record Management System developed in C++ as part of the SkillMe Virtual Internship — Week 1 milestone.

## Project Overview

AlgoCore is a command-line application that allows users to add, store and display student records. It uses structures, vectors, functions and input validation to demonstrate fundamental C++ programming and problem-solving concepts.

## Features

- Add new student records.
- Display all stored student records in a formatted table.
- Validate student names and numeric inputs.
- Prevent duplicate roll numbers.
- Restrict marks to the range of 0–100.
- Identify the student with the highest marks.
- Handle empty student records.
- Provide a menu-driven interface.

## Technologies Used

- C++
- Standard Template Library (STL)
- `std::vector`
- Structures and functions
- Input/output stream handling

## Compilation

Compile the application using:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic -o toolkit main.cpp
```

## Execution

On Windows:

```powershell
.\toolkit.exe
```

On Linux:

```bash
./toolkit
```
